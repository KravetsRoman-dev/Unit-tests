# Лабораторная работа №4. Написание Unit-тестов

## 1. Цели и задачи тестирования

**Цель тестирования** — проверить корректность работы функций вычисления площади и периметра геометрических фигур (круга, прямоугольника и квадрата) с использованием модульного тестирования.

Для достижения поставленной цели необходимо решить следующие задачи:

- Проверить правильность вычисления площади каждой геометрической фигуры.
- Проверить правильность вычисления периметра каждой геометрической фигуры.
- Проверить работу функций на нулевых, целых и вещественных входных значениях.
- Проверить корректность результатов при обработке большого количества различных входных данных.
- Автоматизировать проверку функций с помощью библиотеки `unittest`.

## 2. Описание тестируемого продукта

Тестируемый продукт представляет собой набор модулей на языке Python, реализующих вычисление геометрических характеристик трёх фигур:

- **Круг** — вычисление площади и длины окружности по заданному радиусу.
- **Прямоугольник** — вычисление площади и периметра по двум заданным сторонам.
- **Квадрат** — вычисление площади и периметра по заданной стороне.

Каждый модуль содержит две функции:

- `area` — вычисление площади фигуры.
- `perimeter` — вычисление периметра фигуры.

## 3. Область тестирования

В рамках лабораторной работы тестированию подлежат следующие модули и функции:

| Модуль | Функция | Проверяемая функциональность |
|---|---|---|
| `circle.py` | `area` | Вычисление площади круга |
| `circle.py` | `perimeter` | Вычисление длины окружности |
| `rectangle.py` | `area` | Вычисление площади прямоугольника |
| `rectangle.py` | `perimeter` | Вычисление периметра прямоугольника |
| `square.py` | `area` | Вычисление площади квадрата |
| `square.py` | `perimeter` | Вычисление периметра квадрата |

## 4. Стратегия тестирования

Для проверки корректности работы отдельных функций используется модульное тестирование с помощью стандартной библиотеки Python `unittest`.

Тесты объединены в классы, наследуемые от `unittest.TestCase`. Каждый тестовый метод имеет имя, начинающееся с `test_`.

Используются следующие подходы к тестированию:

- **Проверка граничных значений:** вычисление площади и периметра при нулевых входных параметрах.
- **Проверка стандартных значений:** вычисление результатов для единичных и других целочисленных входных параметров.
- **Проверка вещественных значений:** вычисление результатов для дробных входных параметров.
- **Массовое тестирование:** проверка функций на большом количестве целочисленных входных данных.
- **Сравнение результатов:** использование методов `assertEqual` для точного сравнения результатов и `assertAlmostEqual` для сравнения вещественных чисел с заданной допустимой погрешностью.

Для проверки отдельных наборов входных данных применяется `subTest`, позволяющий определить конкретные параметры, на которых произошла ошибка, без прекращения выполнения остальных проверок внутри тестового метода.

## 5. Критерии приёмки

Тестирование считается успешно завершённым, если:

- Все тестовые методы выполняются без ошибок.
- Результаты вычисления площади и периметра совпадают с математически ожидаемыми значениями.
- Для вещественных результатов отклонение от ожидаемого значения не превышает установленную погрешность.
- Все проверяемые функции корректно обрабатывают предусмотренные тестами входные данные.

## 6. Ожидаемые результаты

В результате тестирования ожидается:

- Подтверждение корректности работы всех шести функций вычисления площади и периметра.
- Выявление возможных ошибок в реализации математических формул.
- Получение отчёта о выполнении тестов с указанием количества успешно пройденных и неуспешных проверок.
- Размещение исходного кода тестов в репозитории GitHub.

## 8. Запуск тестов

Для запуска тестов необходимо перейти в корневую директорию проекта и выполнить команду:

```bash
python3 unit-test/test.py
```

Для запуска используется библиотека `unittest`, входящая в стандартную библиотеку Python, поэтому установка дополнительных зависимостей не требуется.

## 9. Результаты тестирования

После запуска тестов в терминале отображается информация о выполнении каждого тестового метода.

В случае успешного прохождения всех проверок выводится итоговая статистика с количеством выполненных тестов и статусом `OK`.
